# Welcome Message

We are keen to welcome you to our world. Please follow the instructions as shown.

## Short Code

Use the function short_form to create a short code. Be creative but not too creative.

```python
sc = short_form(idx, a few words about yourself, prefix = '', suffix = '')
```
For example,
```python
sc = short_form(0, 'Smart', 'Intelligent', prefix = 'Mr.', suffix = 'Great')
```

Note, you don't _actually_ have to be really the words you are using, we don't care.

## Name strength
